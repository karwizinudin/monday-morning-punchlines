## The entry

`main.py` (Python 3.13, standard library only) scores six original
Monday-morning punchlines against the judge's five criteria — Monday
mornings, a real laugh, surprise, economy of words, freshness — and writes
the winning one-liner to `/output/entry.txt`.

The winning line:

> I told my boss I identify as a weekend. HR said my identity is respected, but Monday still starts at nine.

## Run it

```sh
python3 main.py
```
